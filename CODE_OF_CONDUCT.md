# Code of conduct

Contributors and maintainers must treat others respectfully. Discuss code and
ideas with evidence. Harassment, discrimination, threats, sexualized conduct,
and publishing another person's private information are unacceptable.

Maintainers may remove harmful content and restrict participation. Apply rules
consistently, explain decisions and avoid retaliation against good-faith reports.
Report concerns privately to a maintainer through an available repository
contact. A dedicated moderation contact is not yet designated. Do not include
private reports in public issues.
